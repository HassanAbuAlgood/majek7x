# 9️⃣ إزاي تختار التارجت — نظام تقييم رقمي

> **سؤالك المهم**: "أختار بناءً على إيه؟"
> الجواب: **مش بالشهرة، مش بحجم الشركة، بل بمعايير بتحدد احتمال إنك تلاقي IDOR فعلًا وتتقبل.**

---

## 🎯 الخلاصة في سطر

> **أفضل هدف لمبتدئ متخصص في IDOR:**
> تطبيق **B2B SaaS** فيه **multi-tenancy + أدوار وفرق**، عنده **API واضح + تطبيق موبايل**،
> برنامجه **عمره 1-4 سنين**، متوسط مكافأته **> $500**، و**الـ triage فيه أسرع من 14 يوم**.

ليه؟ لأن:
- الـ multi-tenancy = كائنات مملوكة لمستخدمين = **المادة الخام للـ IDOR**
- الـ B2B عنده أدوار (`admin`, `member`, `viewer`) = مساحة للـ escalation
- البرنامج اللي عمره متوسط = ات hunting بس لسه فيه حاجات
- التطبيق الموبايل = الـ API بتاعه غالبًا أقدم وأقل حماية من الويب

## 📊 نظام التقييم (من 40 نقطة)

قيّم كل هدف على 8 معايير، كل واحد من 5:

| # | المعيار | 0 = سيء | 5 = ممتاز |
|---|---|---|---|
| 1 | **تعدد المستخدمين / tenancy** | موقع ثابت، مفيش حسابات | كل مستخدم عنده كائناته الخاصة |
| 2 | **وجود API / موبايل** | مفيش API مرئي | REST + GraphQL + تطبيق موبايل |
| 3 | **تعقيد الصلاحيات** | دور واحد بس | أدوار + فرق + صلاحيات دقيقة |
| 4 | **اتساع الـ Scope** | نطاق واحد ضيق | `*.domain` + نطاقات فرعية + موبايل |
| 5 | **عمر البرنامج / تشبّعه** | 10 آلاف تقرير قديم | جديد أو متوسط (1-4 سنين) |
| 6 | **المكافآت** | VDP بلا فلوس | متوسط > $500 ومدى واضح |
| 7 | **سرعة الـ Triage** | أشهر بلا رد | median أول رد < 7 أيام |
| 8 | **جودة التوثيق** | مفيش scope واضح | scope مفصل + rules واضحة |

### تفسير النتيجة

| النقاط | القرار |
|---|---|
| **32-40** | 🟢 **ذهبي** — ابدأ فورًا وخصص له 60% من وقتك |
| **24-31** | 🟡 **جيد** — يستحق الاستطلاع |
| **16-23** | 🟠 **متوسط** — اتركه للمرحلة التانية |
| **< 16** | 🔴 **تجاوزه** — هتضيع وقتك |

## 🟢 علامات خضرا (اده Priority)

| العلامة | ليه |
|---|---|
| ✅ `New program` أو أُضيف مؤخرًا | أقل تشبّعًا |
| ✅ استحوذوا على شركة جديدة أو أضافوا feature جديدة | كود جديد = ثغرات جديدة |
| ✅ فيه تطبيق موبايل (iOS/Android) | APIs قديمة ومكشوفة |

| ✅ الـ Scope بيضم نطاقات `staging`/`dev` | الحماية أضعف هناك 👈 |
| ✅ فيه `Safe harbor` مذكور صراحة | أمان قانوني |
| ✅ الـ triager بيرد بتفاصيل | هتتعلم من ردوده |

## 🗂️ القايمة الذهبية: اصنع 5 تارجتات

مش هدف واحد — **5**. وليه؟

```
الهدف 1 (ذهبي)   ← 60% من وقتك
الهدف 2 (جيد)    ← 25%
الهدف 3 (جيد)    ← 10%
الهدف 4 (احتياط) ← 5%
الهدف 5 (احتياط) ← للتبديل لو الهدف 1 اتحظر أو اتحسم
```

**قاعدة**: لو قضيت 3 أسابيع على هدف بدون أي finding، بدّله.
إصرارك على هدف ميت = أسوأ عدو ليك.

## 🧠 أخطاء المبتدئين في اختيار الهدف

| الخطأ | الصح |
|---|---|
| يروح لأكبر برنامج (Google, Microsoft) | ❌ آلاف الباحثين عليه |
| يختار بالشهرة | ❌ اختار بالمعايير |
| يغير الهدف كل يومين | ❌ اديه 2-3 أسابيع على الأقل |
| يختار هدف مفيش فيه حسابات مستخدمين | ❌ مفيش IDOR هناك أصلًا |
| يبدأ بـ VDP بلا مكافآت ويستنى فلوس | ❌ VDP للتدريب والسمعة |

> 🎯 **الحقيقة**: أول bounty ليك غالبًا هيجي من هدف **متوسط الحجم مش معروف**،
> مش من شركة الـ FAANG. اختر بذكاء مش بالطموح.
