# 1️⃣5️⃣ بطاقات المراجعة السريعة

> راجعهم 10 دقايق كل يوم قبل الصيد. التكرار هو اللي بيخلّي المعرفة متاحة وقت اللزوم.

---

## 🧱 الأساس

| السؤال | الجواب |
|---|---|
| **401 vs 403؟** | 401 = مش عارفك. 403 = عارفك ومانعك ← **403 يعني الكائن موجود** |
| **403 vs 404 oracle؟** | 403 = موجود وممنوع. 404 = مش موجود أو مخفي. الفرق = دليل وجود |
| **AuthN vs AuthZ؟** | AuthN = مين أنت (مرة). AuthZ = تقدر تعمل إيه (**كل طلب**) |
| **Horizontal vs Vertical؟** | Horizontal = نفس المستوى/مستخدم تاني. Vertical = صعود أعلى (أخطر) |
| **BOLA vs BFLA؟** | BOLA = كائن (`/orders/8821`). BFLA = وظيفة (`/admin/users`) |
| **Mass Assignment؟** | ربط كل حقل بالكائن تلقائيًا → `{"role":"admin"}` |
| **JWT بينقسم لإيه؟** | `header.payload.signature` (كل واحد base64) |
| **ثغرات JWT؟** | `alg:none` · عدم التحقق · key confusion · `kid` injection |
| **UUID آمن؟** | ❌ مش قابل للتخمين بس **بيتسرب** في أماكن تانية |
| **ObjectId (Mongo)؟** | timestamp + machine + pid + counter = 24 hex |

## 🎯 الـ IDOR

| السؤال | الجواب |
|---|---|
| **معادلة IDOR؟** | (معرّف كائن من المستخدم) × (غياب فحص ملكية) |
| **أنواعه؟** | Read · **Write** (أخطر) · Delete · Create-in-tenant · Function-level |
| **Read → Critical إزاي؟** | Write IDOR → غيّر الإيميل → password reset → **ATO** |
| **أول حاجة بعد 403؟** | غيّر الـ method: `GET → POST/PUT/PATCH/DELETE` |
| **هيدرات التخطي؟** | `X-Original-URL` · `X-Rewrite-URL` · `X-Forwarded-For: 127.0.0.1` |
| **تخطي المسار؟** | trailing slash · `//` · `;` · `%09` · traversal · case |
| **Second-Order IDOR؟** | أنشئ كائن → اربطه بمكان تاني → اقرأه من هناك |
| **Autorize بتعمل إيه؟** | بتعيد كل request بتوكن منخفض وتقارن → `Bypassed!` |
| **ليه حسابين؟** | تثبت إن **مستخدم تاني** يوصل لبيانات الضحية |
| **أين يختبئ الـ ID؟** | path · query · body · header · cookie · JWT · GraphQL |

## 🔍 الاستطلاع والصيد

| السؤال | الجواب |
|---|---|
| **أفضل هدف؟** | B2B SaaS + multi-tenant + أدوار + API/موبايل + برنامج عمره 1-4 سنين |

| **فخ المبتدئين؟** | 90% استطلاع و10% اختبار ← عكس الصح |
| **كم تارجت؟** | **5** — واحد ذهبي بـ 60% وقت + احتياطيين |

## 📝 التقارير

| السؤال | الجواب |
|---|---|
| **عنوان ممتاز؟** | المسار + نوع الثغرة + من يقدر + النتيجة |
| **`Informative` ليه؟** | أثبتّ الوصول بس بدون تأثير عملي |
| **CVSS للـ read IDOR PII؟** | AV:N/AC:L/PR:L/UI:N/S:U/C:H/I:N/A:N = **7.5 High** |
| **IDOR → ATO؟** | **9.x Critical** |
| **أهم عنصر في التقرير؟** | **التأثير بالأرقام** — كم مستخدم؟ إيه نوع البيانات؟ |
| **الإصلاح المقترح؟** | `get(id=..., owner_id=request.user.id)` + 404 بدل 403 |
| **`Duplicate` معناه؟** | حد سبقك — إشارة إنك في الطريق الصح، كمل |

## ⚡ الأوامر السريعة

```bash
# استطلاع
subfinder -d target.com -o subs.txt
httpx -l subs.txt -o live.txt
echo target.com | gau > urls.txt
cat live.txt | getJS --complete > js.txt

# تصفية البارامترات المثيرة
grep -Ei "id=|user|account|order|doc|file|team|key" urls.txt > hot.txt

# فك base64
echo "NDI=" | base64 -d

# فك JWT payload
echo "eyJ1c2VyX2lkIjo0Mn0=" | base64 -d
```
