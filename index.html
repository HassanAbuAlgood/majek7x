SNIPPET № 042 — PYTHON

A TCP connect scan in 15 lines

Sometimes you don't need nmap — you need to know if one port is open on one host, fast, from any machine with Python. connect_ex() returns an error code instead of throwing, so closed ports cost you nothing but the timeout.

  • connect_ex() — error code, not exception, zero try/except noise
  • ThreadPoolExecutor — 64 sockets probed at the same instant
  • 0.5s timeout — don't stare at closed ports, move on

Thanks for reading.
